Privacy Policy

Last updated:

1. Data We Collect

None. This application is fully client-side. The JSON files you upload are read directly by your browser's JavaScript engine and are never transmitted to any server. We do not use cookies, localStorage, analytics, or any third-party tracking.

2. How Your Files Are Processed

When you select a file via the file input, the browser uses the FileReader API to read it into memory locally. The parsed data is used only to compute the set difference between your followers and following lists. Closing or refreshing the tab clears everything.

3. Third Parties

The site is hosted on Vercel. Vercel may log standard HTTP request metadata (IP address, user agent) as part of normal hosting operations. See Vercel's Privacy Policy.

4. Your Rights

Because we do not collect or store any personal data, there is nothing to request, delete, or export. You retain full control of your Instagram data export at all times.

5. Contact

Questions? Open an issue on the GitHub repository.
